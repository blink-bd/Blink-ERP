# تقرير التحقق والاختبار

تاريخ التحقق: 2026-10-12 · البيئة: Node 22.22.3، PostgreSQL 16.2 (قاعدة اختبار محلية `blink_erp_test` / `blink_erp_flow`).

هذا التقرير يوضح ما تم تشغيله فعلياً وما لم يتم تشغيله. لم يُنفَّذ نشر على Render من بيئة التطوير هذه، لذلك لا يوجد ادعاء بنشر ناجح.

### 🟡 موجود ويحتاج إعداداً من مالك النظام

| البند | المتغيرات/الخطوات المطلوبة |
| --- | --- |
| إرسال بريد فعلي | في Render: `MAIL_USER` (blinkbusinessdevelopment@gmail.com) و`MAIL_PASSWORD` = Google App Password. باقي القيم مضبوطة في `render.yaml`. ثم «الإعدادات ← التنبيهات» → إرسال اختبار. |
| إرسال WhatsApp فعلي | في Render: `WHATSAPP_PHONE_NUMBER_ID` و`WHATSAPP_ACCESS_TOKEN` من Meta. الافتراضي للمستلم `+201024898091` عبر `WHATSAPP_TO`. |
| رسائل WhatsApp الاستباقية/خارج نافذة 24 ساعة | قالب معتمد من Meta يحتوي متغيراً `{{1}}`، ثم `WHATSAPP_TEMPLATE_NAME` و`WHATSAPP_TEMPLATE_LANGUAGE`. بدون القالب قد يرفض Meta الرسائل خارج النافذة. |
| تشغيل مهام GitHub المجدولة | Repository Secrets: `API_PUBLIC_URL` + `REMINDERS_JOB_TOKEN` (من قيمة Render) للتذكيرات، و`DATABASE_URL` + `BACKUP_S3_ENDPOINT` + `BACKUP_S3_BUCKET` + `BACKUP_S3_ACCESS_KEY_ID` + `BACKUP_S3_SECRET_ACCESS_KEY` (+ `BACKUP_ALERT_TOKEN`) للنسخ. آخر تشغيل لسير التذكيرات فشل لأن الأسرار غير مضافة بعد. |
| الاحتفاظ بالنسخ | سياسة Lifecycle على مخزن S3؛ لا حذف تلقائي من السكربت. |
| التحقق من مفتاح 2FA في Render | تأكد من وجود `MASTER_2FA_ENCRYPTION_KEY` في Environment بدون طباعة قيمته، ولا تغيّره بعد تفعيل 2FA. |
| قفل لوحة المدير بالـ IP (اختياري) | `MASTER_ADMIN_ALLOWED_IPS` غير مطلوب ولا يوقف الخدمة عند غيابه (IP متغير لدى المالك). لا تستخدم `*` أو `0.0.0.0/0`. |
| النشر على Render | لم يُنفَّذ من هنا؛ بعد الدمج راجع Deploy Logs ثم `/api/v1/health`. |

## 3. ملاحظات تشغيلية

- تكامل API يتم على قاعدة اسمها يحتوي `test/staging/local/ci`، وإلا يرفض الاختبار التشغيل حمايةً للبيانات.
- مزودو الإرسال غير مضبوطين في هذه البيئة، لذلك القنوات تُسجَّل `skipped` — لا يُدَّعى إرسال رسالة حقيقية قبل ضبط الأسرار وإرسال اختبار من صفحة الإعدادات.
- الخطة المجانية في Render تُدخل الخدمة في سكون عند عدم الاستخدام، والمهام المجدولة تُنفَّذ من GitHub Actions وليست مضمونة التشغيل داخل Render.
