## 0) تصحيح عاجل (قاعدة البيانات الحالية على Supabase)

راجعت كل أوامر SQL اللي نفذتها، ولقيت إنها غطّت كل الجداول **إلا اتنين**: `expenses` و `payments`. دول بالظبط سبب العطل اللي ظهر في صفحة المصروفات.

**شغّل ده في Supabase SQL Editor فورًا (لو لسه ما عملتهوش):**
```sql
ALTER TABLE expenses ADD COLUMN IF NOT EXISTS updated_at timestamp without time zone NOT NULL DEFAULT now();
ALTER TABLE expenses ADD COLUMN IF NOT EXISTS deleted_at timestamp without time zone;

ALTER TABLE payments ADD COLUMN IF NOT EXISTS updated_at timestamp without time zone NOT NULL DEFAULT now();
ALTER TABLE payments ADD COLUMN IF NOT EXISTS deleted_at timestamp without time zone;
```

هتلاقي نفس الكود ده دلوقتي جزء رسمي من نظام الـ migrations بتاع المشروع (ملف `1700000000014-FixMissingAuditColumns.ts`)، فمرة ما تعيد نشر الباك إند الجديد، هيتأكد لوحده إن كل الأعمدة موجودة — حتى لو شغّلت الأمر اليدوي فوق أو لأ.

## 3) نقطة البيع (POS)

**استرجاع منتج:** اتضاف كوظيفة كاملة جديدة (كانت الجداول موجودة بس مفيش كود يشغّلها خالص):

## ملاحظات صراحة عن حدود هذا التحديث

- **تصدير PDF** للعملاء بيتم عن طريق **نافذة طباعة** (Print → Save as PDF)، مش مكتبة PDF منفصلة — ده اختيار عملي عشان نتجنب حزم تقيلة زيادة، والنتيجة شغّالة بنفس الشكل المطلوب (قابل للطباعة والحفظ).
- **طباعة الفاتورة A5** بنفس الطريقة (نافذة طباعة بمقاس A5 محدد في CSS)، مش قالب تصميم جاهز — تقدر تطلب تحسين الشكل (لوجو، هيدر مخصص) في خطوة لاحقة.
- **الكود ده اتكتب لكن ما اتشغّلش فعليًا عندي** (بيئتي بدون إنترنت لتثبيت الحزم وتجربته). فحصت توازن الأقواس والبنية في كل الملفات (140 ملف باك إند + 32 ملف واجهة، صفر مشاكل)، لكن لسه محتاج تجربة حقيقية بعد النشر. أي خطأ يظهرلك، ابعتلي نصه وهصلحه فورًا.
- **صلاحيات الأدوار (كاشير مختلف عن مدير)**: لسه نفس الملاحظة القديمة — مفيش Enforcement حقيقي للصلاحيات، كل مستخدم مسجّل دخول يقدر يعمل أي حاجة حاليًا.
