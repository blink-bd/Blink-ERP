# حالة المشروع الحالية

## معلومات عامة

- **النوع:** Web ERP/POS متعدد المستأجرين.
- **Backend:** NestJS Modular Monolith.
- **Frontend:** React + Vite Web App.
- **Database:** PostgreSQL.
- **اللغة الأساسية:** عربي RTL.
- **الحالة:** النظام يعمل، ومغطى باختبارات وحدة (52) واختبارات تكامل على PostgreSQL حقيقي (46). راجع [VERIFICATION_REPORT.md](./VERIFICATION_REPORT.md) للنتائج وخطوات الإعداد المتبقية.

## يحتاج إلى استكمال

- 🟡 اختبارات Concurrency للمخزون وأرقام المستندات (الاختبارات الحالية تغطي الذرية وليس التزامن).
- 🟡 اختبارات واجهة آلية (التحقق الحالي عبر typecheck/build/lint).
- 🟡 DTOs إضافية لبعض نماذج الإدارة البسيطة.
- 🟡 Pagination مرئي كامل في كل الجداول الكبيرة.
- 🟡 إعادة محاولة تلقائية لـ Webhooks (غير منفّذة؛ الواجهة تعرض المحاولات فقط).
- 🟡 ربط رسمي بمنظومة الإيصال الإلكتروني الضريبي المصري (يحتاج اعتماداً وبيانات من مصلحة الضرائب).
- 🟡 Monitoring وTracing مركزي (Health Check للنشر موجود: `/api/v1/health`).
- 🟡 ضبط أسرار Render/GitHub للقنوات والمهام المجدولة — القائمة الدقيقة في VERIFICATION_REPORT.md.
- 🟡 مراجعة Dependency vulnerabilities وتحديث الحزم تدريجيًا.

## الأولوية قبل الإنتاج

1. تشغيل migrations على نسخة قاعدة بيانات تجريبية.
2. اختبار أن كل Role يرى ويعدل ما يسمح به فقط.
3. اختبار أن أي Tenant لا يستطيع قراءة أو تعديل Tenant آخر.
4. اختبار فشل منتصف عملية البيع والتأكد أن المخزون والرصيد يعودان كما كانا.
5. اختبار مرتجعات جزئية ومتعددة لنفس الصنف.
6. اختبار طلبين متزامنين على نفس المخزون.
7. اختبار الضغط على التقارير والقوائم.
8. تنفيذ QA للـ Web على الهاتف والتابلت والكمبيوتر.
